# Data folder (auto-discovery)

This folder is **user-editable**. You can add new datasets here without editing any package code or config mappings.

## Add a new dataset (no config edits)

1) Drop your CSV into this folder.

2) The file name **must start** with the dataset ID prefix, e.g.:

- `ds19_mydata.csv` (example)

3) Auto-discovery uses the prefix (`ds19`) to find the dataset file.

## Dataset requirements (minimum)

- CSV must have a **datetime index** in the first column (same style as `ds0_test.csv`).
- CSV must contain a target column named `netload_kW` (the engine renames it to `y`).

## Run the dataset (4-key spec only)

Edit `../specs/experiment.yaml`:

```yaml
dataset: ds19
forecast_horizon: fh1
model: m6
hyperparameter: hp1
```

Then run:

```bash
python -c "import pynnlf; pynnlf.run_experiment('PATH_TO_WORKSPACE/specs/experiment.yaml')"
```

## Gotchas

- Auto-discovery requires **exactly one** match for a dataset ID. If you have `ds19_a.csv` and `ds19_b.csv`, the runner will raise an error asking you to rename.
- If your file is huge, keep it out of Git history (use `.gitignore`).

## Publication datasets in this folder

- `ds20`: ASHD 148-household weather dataset.
- `ds22`-`ds24`: clean SA BESS 44-household datasets with no meaningful negative reconstructed underlying-load intervals.
- `ds11`: ACAP-EDP 148-household (Cluster 2) weather dataset.
- `ds28`-`ds36`: ACAP-EDP aggregation-level datasets (10, 100 and 1000 households, 3 samples per level) generated by `../notebooks/03_acap_edp_aggregation_level/1_build_acap_edp_site_30min_checkpoints.ipynb` and `../notebooks/03_acap_edp_aggregation_level/2_generate_acap_edp_aggregation_datasets.ipynb`. The single-household samples `ds25`-`ds27` are not distributed.
- `ds37`-`ds38`: UMass Smart* SunDance hourly aggregate for North America (2015), without and with site-mean weather, generated by `../notebooks/00_data_exploration_and_processing/02_process_international_datasets/1_process_sundance_hourly.ipynb`.
- `ds39`-`ds40`: Fluvius solar-household half-hourly aggregate for Belgium (2024), without and with Brussels-Uccle weather, generated by `../notebooks/00_data_exploration_and_processing/02_process_international_datasets/2_process_fluvius_pv_30min.ipynb`.
